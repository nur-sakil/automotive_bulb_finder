# Car Models & Bulb Fitment Guide (2000–2025)

An interactive web directory and dataset covering automotive bulb fitment codes across **2000–2025** model years for **Toyota, Hyundai, Kia, Ford, GMC, Cadillac, Chevrolet, and Mercury** across **Saudi Arabia / GCC, US / North America, Europe, and Global** markets.

---

## Suggested GitHub Metadata

* **Repository Heading / Title:** `automotive bulb finder`
* **Short Repository Description:** Interactive HTML directory and CSV dataset of automotive bulb codes (Low/High Beam, Fog, Turn Signals, Brake/Tail, Reverse, License Plate) for 2000–2025 models across GCC, US, Europe, and Global markets.

## Web Application Features (`car_bulb_guide_2000_2025.html`)

* **Multi-Criteria Filtering:** Filter by Brand, Model / Keyword, Bulb Code (such as `H11`, `9005`, `H4`, `D3S`, `7443`, `921`, `168`), Model Year range (`2000–2025`), and Market / Region.
* **Sorting & Pagination:** Sort by any column ascending or descending and choose how many rows to display (`25`, `50`, `100`, or `All rows`).
* **Filtered CSV Export:** Download a `.csv` file of the currently filtered table rows directly in the browser.

---

## Fitment Notes

* **Trim & Regional Variations (`/`):** Multiple codes separated by `/` indicate differences across trims, lighting technologies (Halogen, HID/Xenon, LED), or regional specifications.
* **Dual-Beam Bulbs:** Matching Low Beam and High Beam codes (such as `H4 (9003)`, `9007`, `H13`, or `9012`) indicate a single dual-filament bulb.
* **Integrated LEDs:** Newer assemblies with non-replaceable factory LEDs are marked `LED (Integrated)`.
* **Regional Naming:** Equivalent US and GCC/Europe designations are shown where applicable (e.g., `168 / 194` = `W5W`, `921` = `W16W`, `1156A` = `PY21W`, `1157` = `P21/5W`, `9005` = `HB3`, `9006` = `HB4`).
